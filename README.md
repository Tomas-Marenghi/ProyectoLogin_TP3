Descripción del proyecto:

Este proyecto es un sistema de login y registro simple realizado como introducción a la creación de este tipo de proyectos. Se realizó usando la lista de videos tutoriales provista en el formulario de entrega. Las herramientas que se usaron son: Visual Studio Code, phpMyAdmin, Apache, MySQL.

¿Cómo instalarlo?

Creá una carpeta llamada "ProyectoLogin" dentro de C:\xampp\htdocs
Copiá todos los archivos del repositorio dentro de ella
Luego abrí phpMyAdmin e importá el archivo sql/db_login.sql
Encendé Apache y MySQL desde el panel de XAMPP
Entrá a http://localhost/ProyectoLogin desde un navegador

Detalles del sistema:

- index.php: Script con la estructura fundamental de la página de login, usa código en HTML.
- bienvenido.php: La página a la que se ingresa una vez iniciada la sesión.
- DB.sql: La base de datos exportada directamente desde phpMyAdmin.
- estilos.css: Script el cual le da formato, color, estilo y animaciones a la página de login/registro.
- script.js: Contiene funciones fundamentales para la correcta presentación de la pagina de login/registro.
- conexion_be.php: Maneja la conexion con la base de datos.
- login_usuario_be: Maneja el sistema de inicio de sesion.
- registro_usuario_be: Maneja el sistema de registro de usuarios.
- cerrar_sesion: Maneja el sistema de cierre de sesion.
